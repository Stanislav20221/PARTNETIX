PARTNETIX
О проекте

PARTNETIX — это веб-платформа для автоматизации работы с партнерской программой компании.

Система объединяет администратора и партнеров в едином личном кабинете, позволяя управлять офферами, лидами, выплатами, обучающими материалами и коммуникацией между участниками программы.

Проект разработан на Python/Django с использованием современных технологий веб-разработки и искусственного интеллекта.

Основные возможности
Для администратора
управление партнерами;
создание и редактирование офферов;
назначение офферов партнерам;
управление лидами;
изменение статусов лидов;
расчет партнерских вознаграждений;
управление заявками на вывод средств;
публикация обучающих материалов;
публикация маркетинговых материалов;
встроенный чат с партнерами;
просмотр статистики работы партнеров.
Для партнера
личный кабинет;
просмотр доступных офферов;
получение партнерских ссылок;
просмотр начислений;
подача заявок на вывод средств;
работа с лидами;
доступ к обучению;
получение маркетинговых материалов;
чат с администратором.
Возможности системы
ролевая модель пользователей;
адаптивный интерфейс;
система уведомлений;
загрузка файлов;
управление документами;
безопасная авторизация;
разграничение прав доступа;
WebSocket-чат в реальном времени;
фильтрация и поиск данных;
административная панель Django.
